# 可信医学问答与知识发布

## 运行边界（百科模式）

系统采用**双信任层**，而不是「未审核即隐藏」：覆盖面来自完整目录，
安全性来自每条结果都必须带层级标注。

| 层级 | 来源 | 用户可见性 |
| --- | --- | --- |
| `PUBLISHED` | 经审核、带权威 HTTPS 来源（WHO 等） | 可直接引用来源 |
| `LEGACY_UNREVIEWED` | `agent/data/medical.json` 开源医学百科目录 | 展示，但必须标注「未经逐条人工审核，仅供参考」 |

- 图查询与向量检索都覆盖两层。检索层不再假装未审核数据不存在，
  而是把真实层级（节点的 `reviewStatus` + HTTPS 来源）随结果返回。
- Qdrant 索引覆盖全量疾病目录，`governance_status` 随每个点存储；
  索引重建仍采用租户级替换。
- 两层都要求 HTTPS 来源；目录层携带上游数据集地址。
- `agent/src/yuanqi_agent/resources/knowledge_governance.v1.json` 保存精确到
  `entityKey` 的检索排除规则。标准化脚本会把命中实体标记为
  `retrievalStatus = EXCLUDED`，GraphRAG 在融合前再次应用同一策略，避免旧图
  或旧向量索引绕过治理。
- **药物**是唯一例外：适应证、用法、剂量、禁忌只在 `PUBLISHED` 层展示。
  目录中的药物—疾病关联只呈现为「在以下疾病条目中出现过」，明确不是适应证。
- 检查报告模式与知识图谱隔离，只使用报告原文、结构化指标和用户补充信息。

## 实体识别

面向用户的问句先在全量图谱上做实体名最长匹配（Disease / Drug / Symptom /
Department），命中后路由到对应的强类型工具。早期版本用一份写死的关键词表，
只覆盖 22 个疾病，目录中其余 8000 多个疾病无法被指名查询。

## 发布流程

1. 在“医学知识维护与发布”中创建知识文档，填写权威 HTTPS 来源和至少
   200 字的正文。
2. 草稿送审，审核人确认事实、适用人群、时效和来源后发布。
3. 点击“重建向量索引”。新语料会先完成校验和向量计算，再替换当前租户语料。
4. 成功版本标记为 `ACTIVE`，上一个活动版本自动变为 `SUPERSEDED`；失败版本
   标记为 `FAILED`，不会伪装成成功。

## Neo4j 发布契约

用户可见节点必须包含：

- `reviewStatus = "PUBLISHED"`
- `sourceUri`，且以 `https://` 开头
- `sourceTitle`
- `knowledgeVersion`
- `reviewedAt`、`reviewedBy`

用户可见关系必须包含：

- `reviewStatus = "PUBLISHED"` 或 `reviewed = true`
- `sourceUri`，且以 `https://` 开头
- `reviewedAt`、`reviewedBy`

首批可信子图可重复执行：

```powershell
cd agent
.\.venv\Scripts\python.exe scripts\publish_trusted_medical_subset.py
```

脚本只发布明确列出的可信子集，不删除或批量批准旧数据。

药品分类事实、标签安全提醒、来源和知识版本统一维护在
`agent/src/yuanqi_agent/resources/trusted_drugs.v1.json`。发布脚本从该资源写入
Neo4j；运行时在新知识版本尚未完成发布时也从同一资源读取安全提醒，不再在
SSE 展示代码中维护第二份医学内容。

## 回答约束

- 疾病关系使用“常见症状线索”“可能并发症”“医生可能结合使用的检查”等
  谨慎语义，不把关联当作诊断或必做项目。
- 症状查询和目录层疾病回答必须带“未经逐条人工审核、不能据此自行诊断”的标注。
- 药物适应证必须来自已发布说明书字段；未经审核的用法和剂量不展示。
- 每条 GraphRAG 结果都带 `trustScore` 与 `evidenceLevel`（`HIGH` /
  `SUPPORTED` / `INSUFFICIENT`）。评分由来源、发布状态、版本、实体明确程度
  和跨库一致性确定，不是模型自行声称的概率。该评分用于**标注**结果层级，
  不再用作丢弃目录内容的门槛。
- GraphRAG 医学结果采用确定性渲染，保留 `[K1]` 等引用编号；本地模型不能在
  检索完成后加入无引用医学事实。

## 当前覆盖

- **目录层**：约 8800 个疾病、6000 个症状、3800 个药物、3400 个检查项目、
  4800 个食物和 540 种治疗方式，全部可检索、可指名查询，带未审核标注。
- **已审核层**：糖尿病、高血压、抑郁症、哮喘、乙型病毒性肝炎、丙型病毒性
  肝炎、慢性阻塞性肺疾病和癌症等一般健康教育内容，附 WHO 权威来源。

扩大已审核层仍走上面的发布流程；目录层的作用是保证覆盖面，不替代审核。

### 已知数据质量问题

上游开源目录存在少量编码损坏（例如“干燥综合征”简介中的 `Sj鰃ren`）和
个别噪声症状词。这类问题应在目录清洗阶段处理，不影响信任层级判定。
